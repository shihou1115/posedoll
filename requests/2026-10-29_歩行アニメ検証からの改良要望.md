# 改良要望：歩行アニメーション検証で見つかった問題（2026-10-29）

## 経緯
- ComfyUI で「魔女が右から左へ歩く」動画を試作（Anima 派生 MiaoMiao Harem ＋ 参照アダプター ＋ Anima LLLite pose → MiniMax H3 i2v）。
- 最初のコマは本ツールの OpenPose（プリセット「歩く」、腰を Y -90° で真横・左向き、1344×768）から作成。
- 生成画像で「上半身は左向き・後ろ足のつま先は右向き」という解剖学的破綻が発生し、動画でも体の向きが不安定になった。
- 腰の向きを -70°（真横から 20° 手前へ）に変えたところ、向きがそろった1枚が得られ、動画も安定した。
- 関連ファイル（C:\claude\comfyUI_temp）: inputs\walk_left_openpose.png（真横・破綻）, inputs\walk_left34_openpose.png（斜め横・改善）, outputs\walk\

## 原因の整理
1. 真横では左右の肩・左右の腰の点がほぼ重なり、胴体の向きが OpenPose 画像に入らない（向きの手がかりが頭の点だけになる）。
2. COCO-18 の体骨格には足先の点がなく、つま先の向きを指定できない。
3. Anima LLLite pose は効きが弱い（配布元も「弱めのポーズの目安」と説明）。学習データは DWPose 標準出力（体の色付き骨格＋白い顔の点＋手）。

## 要望（優先度順）
1. **真横に近い角度の警告**：カメラから見て胴体がほぼ真横（左右の肩・腰の画面上の距離が小さい）とき、出力タブに「OpenPose では体の向きが伝わりにくい。少し斜めにすると安定します」と表示する。
2. **足先の点の出力**：DWPose の足先あり形式（つま先・小指側・かかと）を選べるようにする。ComfyUI 側（comfyui_controlnet_aux / LLLite pose）がその描き方を受け付けるかは要確認。描画仕様は controlnet_aux の実装に合わせる。
3. **顔の点（白い点）の出力**：LLLite pose の学習形式に合わせ、DWPose の顔の点を任意で描けるようにする（人形の頭の向きから近似で可）。
4. **画面内の配置と大きさ**：書き出し枠の中で人形の位置（左右・上下）と大きさを調整できるようにする。今回は人形を画面右寄り・縮小して置く必要があり、書き出し後に画像処理でずらした。カメラの注視点を人形から独立させる方法でもよい。

## 補足
- 改良後は src/smoke_test.js に、警告の判定や新しい出力形式の確認を追加すること。

## 対応（v1.6、2026-10-30）
1. **真横の警告**：対応。肩の線・腰の線と視線のなす角が両方とも約 17° 未満（真横から 17° 以内）のとき、出力タブの OpenPose プレビューの下に警告を出し、書き出し枠も赤くして「真横に近い」と表示する。人物が複数なら該当する人物名を出す。
2. **足先の点**：対応（出力タブ「足先」）。確認の結果、comfyui_controlnet_aux の DWPose は足の点を検出はするが描画では捨てている（`instance[18:24]` を使わない）ため、controlnet_aux 準拠の描き方は存在しない。代わりに既存の2形式から選べるようにした。
   - 3点（つま先・小指側・かかと）：OpenPose BODY_25 の描き方（左足 青 (0,0,255)、右足 水色 (0,255,255)）。
   - 1点（つま先）：Wan Animate（kijai/ComfyUI-WanAnimatePreprocess）の描き方（親指と小指の中点、左 (200,200,0)、右 (100,100,0)）。
   - 棒の太さ・透明度は体と同じ。キーポイント JSON には `foot_keypoints_2d`（左の親指側・小指側・かかと、右の同じ順の 6点）を追加。
   - LLLite pose / OpenPose ControlNet が足先の描き方を学習しているかは不明。効かない・逆効果なら「描かない」に戻す。
3. **顔の点**：対応（出力タブ「顔の点を描く」）。DWPose と同じ 68 点（iBUG 順）の白い点を、人形の頭の向きから近似で描く（後ろ向きで見えない点は描かない）。点の大きさは DWPose（512px で半径 3）に合わせた。JSON の `face_keypoints_2d` にも入る。
4. **画面内の配置と大きさ**：対応（出力タブ「枠の中の配置」：左右・上下 ±50%、大きさ 40〜250%）。カメラにレンズシフト＋拡大をかける方式なので遠近感は変わらず、画面の枠の見た目がそのまま書き出しになる。全種類の書き出し・一括書き出しに効き、シーン JSON の `cam.place` に保存される。
- smoke_test に `sideWarn` `feetFace` `faceBack` `feetToe` `feetOff` `place` `placeReset` `camOldFile` を追加。
