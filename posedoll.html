ポーズ

言葉でポーズ（LLM）

「指示書をコピー」で、上の文章入りの指示を ChatGPT・Claude・LM Studio などに貼ってください。返ってきた JSON を下の欄に貼ると、選択中の人物がそのポーズになります（このアプリ自体は通信しません）。

ショートカット：Tab／Shift+Tab（または ] ／ [）で次／前の関節、↑↓で前後に曲げ・←→で左右に開く・Ctrl+←→でひねり（1°、Shift で 5°）、R 回転／G 移動（腰・小道具）／S 大きさ（小道具）、1〜6 で視点（正面・斜め・横・背面・俯瞰・あおり）、Esc で選択解除、Ctrl+Z／Ctrl+Y で元に戻す／やり直す。

右上の「IK」をオンにすると、手首・足首とひじ・ひざに青い球が出ます。手首・足首の球を動かすと、ひじ・ひざが自動で曲がります。ひじ・ひざの球（小さい方）も動かせます。ひざは足先がそのまま、ひじは手がなるべく元の位置に残るように動きます。「可動域」をオンにしておくと、関節が人体で無理な角度に曲がりません。

OpenPose 画像は ComfyUI の Load Image から ControlNet Apply に直接つなぎます（DWPose は不要）。手指まで効かせたい場合は、手に対応した OpenPose ControlNet を使ってください。法線は ControlNet normal、線画は lineart / canny 系に使えます（線画は黒地に白い線なので、プリプロセッサは「なし」でつなぎます）。キーポイントは OpenPose 画像と同じ点の座標（ピクセル単位）で、POSE_KEYPOINT を扱うノードや後処理に使えます。顔の点は face_keypoints_2d、足先は foot_keypoints_2d（左の親指側・小指側・かかと、右の同じ順）に入ります。足先の描き方は comfyui_controlnet_aux の DWPose には無く（足の点は描かれない）、効くかは ControlNet / LLLite 側の学習次第です。
