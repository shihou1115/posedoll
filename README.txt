デッサン人形ポーザー v1.5（ローカル版）

■ 起動
  posedoll.html をダブルクリック（Chrome または Edge 推奨）。ネット接続は不要です。

■ 最初の設定
  ・保存庫タブ →「フォルダを選ぶ」→ このフォルダ内の library を選択
  ・出力タブ  →「フォルダを選ぶ」→ ComfyUI の input フォルダなど（任意。未設定ならダウンロード保存）
  ・次回以降、ブラウザに確認されたら「接続を再開」を押してください。

■ フォルダ構成
  posedoll.html  … アプリ本体（これ1つで動きます）
  LLM_POSE.md    … LLM にポーズを書かせるための指示書（アプリの「指示書をコピー」と同じ内容）
  library\       … 保存庫（ポーズ1件 = JSON 1ファイル。コピーすればバックアップ・移行できます）
  src\           … 改修用のソース（app.js / skin.js / template.html / build.py）
  vendor\        … 組み込み済みのライブラリ（three.js r160, JSZip 3.10.1：いずれも MIT ライセンス）

■ v1.5 で増えたこと
  ・言葉でポーズ（ポーズタブ）：作りたいポーズを文章で書いて「指示書をコピー」→ ChatGPT・Claude・LM Studio などに貼る
    → 返ってきた JSON を下の欄に貼ると、選択中の人物がそのポーズになります。アプリ自体は通信しません。
    可動域がオンなら無理な角度は丸めます。大まかな形を作ってから、細部は今までどおり手で直す使い方を想定しています。

■ v1.4 で増えたこと
  ・IK モードで、ひじ・ひざの球（小さい方）も動かせます。
    ひざ：足先はそのままで、ひざの向きが変わります。ひじ：ひじが引いた方へ動き、手はなるべく元の位置に残るよう曲がります。

■ v1.3 で増えたこと
  ・見た目「人体」：関節の継ぎ目がない肌の人形（既定）。体型タブで「デッサン人形」に切り替えられます。
    体型スライダーを動かした直後は粗い形で表示し、手を離すと細かい形に作り直します。

■ v1.2 で増えたこと
  ・出力：法線・線画・キーポイント（OpenPose JSON）の保存、複数アングルの一括保存（ZIP）
  ・シーン JSON に視点・画角・出力サイズも保存（読み込み時に戻すかは出力タブで選択）
  ・ショートカット：Tab で関節送り、矢印キーで 1°（Shift で 5°）、R/G/S、1〜6 で視点（一覧はポーズタブ）

■ 補足
  ・作業中のシーンと各種設定はブラウザ内に自動保存されます。
  ・Firefox ではフォルダ保存が使えないため、保存庫はブラウザ内保存になります。
